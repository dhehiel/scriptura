# Attributions

Verbatim attribution strings required by upstream licences.

Where a licence specifies attribution wording, that wording is reproduced **exactly**. It is not paraphrased,
shortened, tidied, or reformatted. Paraphrasing a mandatory attribution string is prohibited by
[.clinerules/050-data-licensing.md](../../../.clinerules/050-data-licensing.md) §7.

> [!IMPORTANT]
> **No corpus data is present in this repository at M0.** The attributions below are recorded in
> advance, so that the exact wording is captured while the licence evidence is fresh, and so that
> it travels correctly with any future redistribution. Recording an attribution is not an assertion
> that the dataset has been ingested.

## How attributions travel

1. Every attribution recorded here is propagated to [NOTICE](../../../NOTICE) §2 when the corresponding
   dataset is ingested.
2. Every dataset manifest records its attribution verbatim.
3. Every Scriptura data product derived from a licensed dataset carries the attribution of every source
   it derives from.
4. Share-alike derivatives carry their inherited licence, and are **not** relicensed under Apache 2.0.
5. Non-commercial derivatives are marked and quarantined from commercial distribution.

## Verifying

```bash
make check-licences
```

This cross-checks the registry against the manifest, confirms that every licence-cleared source with
`attribution_required: true` has a recorded attribution string, and evaluates the ingestion gate.
